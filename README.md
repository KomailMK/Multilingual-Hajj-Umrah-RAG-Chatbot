# Hajj & Umrah RAG Chatbot

An intelligent, multilingual (English and Arabic) chatbot designed to provide accurate, evidence-grounded guidance for Hajj and Umrah. This application is built using a Retrieval-Augmented Generation (RAG) architecture, ensuring that all answers are sourced directly from trusted Islamic texts and documents.

## Architecture & Pipeline

The project is split into three main components:

1. **Data Ingestion & Vector DB (Jupyter Notebook)**
   - **Tooling:** Python, LangChain, PyPDF2, FAISS, Hugging Face Embeddings.
   - **Process:** Reads multiple PDF documents, merges them, chunks the text, generates embeddings using `sentence-transformers/paraphrase-multilingual-mpnet-base-v2`, and saves them into a local FAISS Vector Database (`vector_db`).
2. **Backend API (Hugging Face Spaces)**
   - **Tooling:** FastAPI, LangChain, OpenRouter (Nvidia Nemotron/Llama 3).
   - **Process:** Hosts the REST API. It loads the pre-built FAISS `vector_db` and uses it to retrieve relevant context based on the user's query. It then prompts the LLM to generate a highly accurate, cited response.
3. **Frontend UI (Vercel)**
   - **Tooling:** Next.js 15, React 19, Tailwind CSS v4, Framer Motion.
   - **Process:** A responsive, modern web interface that communicates with the backend API. It handles state, language switching (LTR/RTL), and renders Markdown responses cleanly.

## How to Expand the LLM's Knowledge Base

The chatbot's knowledge is entirely dependent on the documents processed into the Vector Database. You can easily add more PDFs to make the chatbot smarter.

### Steps to Update the Vector DB:

1. **Add your PDFs:** Place any new PDF documents (e.g., `new_guide.pdf`) in the root directory alongside the Jupyter notebook.
2. **Open the Notebook:** Open `hajj_rag_chatbot_optimized.ipynb` in Jupyter Notebook, VS Code, or Google Colab.
3. **Update the Merge List:** Locate the cell containing the `pdfs_to_merge` list and add your new file names.
   ```python
   pdfs_to_merge = ["Tawaf.pdf", "hajj.pdf", "new_guide.pdf"] # Add your new PDFs here
   ```
4. **Run the Notebook:** Execute all cells in the notebook. 
   - The script will merge the PDFs, extract the text, split it into chunks, and generate new embeddings.
   - A new folder named `vector_db` will be created/updated in your root directory.
5. **Update the Backend:** 
   - Copy the newly generated `vector_db` folder.
   - Replace the old `vector_db` folder located inside the `backend/` directory.
6. **Deploy:** Push your changes to GitHub/Hugging Face to deploy the updated knowledge base.

## Local Development Setup

### 1. Backend Setup
**Prerequisites:** Python 3.9+

```bash
# Navigate to the backend directory
cd backend

# Create a virtual environment (optional but recommended)
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Set your OpenRouter API Key (Required for LLM generation)
export OPENROUTER_API_KEY="your_api_key_here" # On Windows: set OPENROUTER_API_KEY=your_api_key_here

# Run the FastAPI server
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```
The backend will now be running at `http://localhost:8000`.

### 2. Frontend Setup
**Prerequisites:** Node.js 18+

```bash
# Navigate to the frontend directory
cd frontend

# Install dependencies
npm install

# Run the development server
npm run dev
```
The frontend will now be running at `http://localhost:3000`. 
*(Note: To test locally, ensure you update the axios POST URL in `frontend/app/page.tsx` from the Hugging Face URL to `http://localhost:8000/chat`)*.

## Deployment

*   **Backend:** The backend is containerized using the provided `Dockerfile` and is hosted on **Hugging Face Spaces**. Make sure to set the `OPENROUTER_API_KEY` in the Spaces Secrets settings.
*   **Frontend:** The frontend is seamlessly deployed on **Vercel**. Simply connect your GitHub repository to Vercel, set the root directory to `frontend`, and it will build automatically.
